# Ukázky formátů

Vzorové obrázky ke dvěma formátům z `../FORMATY.md`.

## Web – produktové stránky (1820 × 980, na web @2x 3640 × 1960)

`ukazka-web.png` ukazuje, jak obrázek vypadá na produktové stránce:

1. **miniatura v textu** (~600 × 322 px, jak je dnes na aptien.com) – čte se nadpis a velká čísla,
2. **po rozkliknutí** (CMS detail 2880 px) – celý obrázek a výřez 1 : 1, UI je ostré a čitelné.

Šablony pro tento formát: `../sablony-vizualu/` a `Claude-Aptien-Templates/visuals/web-obrazky/`.

## KB – články znalostní báze (šířka 1700, výška podle obsahu)

Šablony a pravidla jsou v **`../sablony-kb/`** (typ A „screen“ a typ B „kombinovaný“).

| Soubor | Typ | Rozměr PNG |
|---|---|---|
| `kb-16x9-tabulka` | A · screen | 1700 × 956 |
| `kb-3x2-karta` | A · screen | 1700 × 1134 |
| `kb-4x3-dialog` | A · screen se zvětšeným detailem | 1700 × 1276 |

`ukazka-kb.png` ukazuje oba typy v článku (sloupec 850 px).
